# CBIR : recherche d'images par le contenu et par mots-clés

Moteur de recherche d'images (atelier « Indexation et recherche d'images par le contenu », SUP'COM) : on cherche par
**l'image**, par **mots-clés**, ou par les deux. Il s'appuie sur des descripteurs visuels, un index de similarité,
Elasticsearch, FastAPI et Docker.
